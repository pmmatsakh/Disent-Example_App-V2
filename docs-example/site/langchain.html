langchain

LangChain chain: prompt template -> Claude -> output parser. Bring your own API key in the UI (used per-request, never stored); a server key is optional.

ai python port 3401 proxy

Live URL

https://my-container-3401.example.com

Run it locally

cd langchain-example/app
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
./.venv/bin/python main.py

Then open http://localhost:3401. Every app also serves /health returning JSON.

How it is deployed

Sourcelangchain-example/app
On the box/srv/apps/langchain
systemd unitexample-langchain.service
Start command.venv/bin/python main.py
./deploy-all.sh langchain

Logs: journalctl -u example-langchain -n 30 --no-pager

Bring your own key. Paste a key into the field on the tile and it is used for that one request — never stored or logged. A server key in .env is an optional fallback. Some rows (mcp_server) need no key at all.
