# Disent Container Examples

Documentation for building and running the example apps that ship inside the
Disent development container.

Each example is a small, self-contained app bound to its own port and surfaced
on the container's homepage.

- [**vite react**](vite-react.md) — a Vite + React "hello world" that runs
  entirely in the browser (the *frontend* row, port 5174).
